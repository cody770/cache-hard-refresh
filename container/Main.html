Cache Clear & Hard Refresh

Two quick steps to set this up.

  1. 1✓ Enable the extension

    Open Safari's Extensions settings, find Cache Clear & Hard Refresh, and turn it on.

    Done. The extension is enabled.

  2. 2 Allow access on all websites

    In the same Extensions settings, with Cache Clear & Hard Refresh selected on the left, change Website Access on the right from Specific Websites to All Websites.

    This is required because Safari's cookies API can't be limited to a single site at the manifest level — it's all-or-nothing. The extension still only ever acts on the tab whose toolbar button you've clicked. View source to verify.

  3. 3 Try it

    Visit any site and click the Cache Clear & Hard Refresh button in Safari's toolbar. A toast will appear listing what was cleared (storage, caches, service workers, IndexedDB, cookies).

What data does this collect?

None. No analytics, no telemetry, no crash reports, no network requests. Nothing leaves your machine. The extension has no servers and never makes a network call of its own.

What does it actually access?

Only the active tab, only when you click the toolbar button. The "all websites" permission Safari requires is a platform constraint — the cookies API doesn't accept per-site scoping at install time. The extension code never touches a tab you haven't explicitly clicked.
